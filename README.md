# АС Учёт ОС — Автоматизированная система учёта основных средств

Веб-система для учёта основных средств (ОС): реестр оборудования по инвентарным
и серийным номерам, контроль технического состояния, местонахождения,
закрепления за сотрудниками и жизненного цикла.

Реализация выполнена строго на основе требований [PRD.md](PRD.md).

## Возможности (v1.0)

- **Панель мониторинга** — сводные метрики, распределение по состояниям, лента событий.
- **Реестр ОС** — добавление/редактирование, поиск по инв./серийному номеру, наименованию и ответственному, фильтры по состоянию и локации, карточка ОС с историей, экспорт в CSV.
- **Учёт состояния** — 4 состояния (рабочее, не рабочее, требует замены, требует модернизации) со сменой по причине и сохранением истории.
- **Закрепление за сотрудниками** — карточки сотрудников и закреплённые за ними ОС.
- **Местонахождение** — распределение ОС по подразделениям с количеством.
- **Перемещения** — акты перемещения со статусами; при завершении локация ОС обновляется автоматически.
- **Обслуживание** — заявки на ТО, диагностику, ремонт, замену компонентов, обновление ПО.
- **Утилизация** — акты списания с причиной и статусом.
- **Отчёты** — сводный отчёт и отчёт по ОС, требующим внимания, с экспортом в CSV/Excel.

## Технологии

Реализовано как клиентское SPA без шага сборки — разворачивается на статическом
хостинге (GitHub Pages):

- **React 18** (UMD) + **Babel Standalone** (JSX в браузере)
- **Tailwind CSS** (Play CDN)
- Хранение данных — **localStorage** браузера (демо-режим, с начальным набором данных)

> Примечание. PRD рекомендует серверный стек (React + Node/FastAPI + PostgreSQL +
> LDAP/SSO, Docker). Поскольку проект публикуется на GitHub Pages — площадке только
> для статики, — здесь представлен полнофункциональный фронтенд-прототип v1.0 с
> сохранением данных в браузере. Замена слоя данных на REST API и БД из PRD не
> требует изменения интерфейса.

## Запуск локально

Отдельная сборка не нужна — достаточно открыть `index.html` в браузере
(или раздать папку любым статическим сервером):

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

Кнопка «↺ Сбросить демо-данные» в боковом меню возвращает исходный набор.
